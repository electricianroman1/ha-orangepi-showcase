# Home Assistant на Orange Pi Zero 3

Заметки и скрипты домашнего Home Assistant (Supervised, Ubuntu 22.04, Orange Pi Zero 3, Zigbee2MQTT).
Всё из рабочей системы; адреса, MAC-адреса и ID заменены плейсхолдерами. Перед использованием читайте скрипты: многие рассчитаны на мою схему именования сущностей.

## Что внутри

| Папка | О чём |
|---|---|
| [docs/ha-stuck-on-32bit.md](docs/ha-stuck-on-32bit.md) | HA Supervised не обновляется выше 2025.11 на 64-битной плате: причина и лечение |
| [docs/zigbee-restarts.md](docs/zigbee-restarts.md) | «Что-то ломается, помогает только перезагрузка платы»: ZHA и Zigbee2MQTT на одном координаторе |
| [docs/telegram-bot.md](docs/telegram-bot.md) | Бот «Умный дом»: меню, роли, надёжная отправка, грабли |
| [bot/](bot/) | Пакет HA `telegram_menu.yaml` (~950 строк), генератор графиков `tg_chart.py`, пример секретов |
| [scripts/update/](scripts/update) | Обновление ядра и дополнений с проверкой, что после старта всё загрузилось |
| [scripts/zigbee/](scripts/zigbee) | Аудит устройств, прослушка MQTT, спаривание, внешний конвертер Z2M для EKF is-th-zb |

## Правила, которые себя оправдали

1. Перед рискованным шагом делать полный бэкап и копировать его на ПК.
2. Менять по одной вещи.
3. Не включать приборы «для проверки»: проверять чтение состояния и смотреть logbook на лишние включения после изменений.
4. Секреты хранить только в `secrets.yaml`, в скриптах и документации их нет.
